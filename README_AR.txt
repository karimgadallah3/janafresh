
=============================================================
دليل تحميل واستخدام موقع Jana Fresh
=============================================================

تم إنشاء الملفات التالية حتى الآن:

✅ الملفات الأساسية:
   - styles.css (ملف CSS متقدم مع أنيميشن)
   - scripts.js (ملف JavaScript للتفاعلات)

✅ الصفحات المُنشأة:
   - index.html (الصفحة الرئيسية)
   - about.html (صفحة من نحن)

⏳ الصفحات المطلوبة المتبقية:
   - products.html
   - quality.html  
   - certificates.html
   - contact.html
   - product-detail.html

-------------------------------------------------------------
طريقة الاستخدام:
-------------------------------------------------------------

1. قم بتحميل جميع الملفات في نفس المجلد
2. تأكد من أن جميع الملفات في نفس المستوى:
   📁 المجلد الرئيسي/
   ├── index.html
   ├── about.html
   ├── products.html
   ├── quality.html
   ├── certificates.html
   ├── contact.html
   ├── product-detail.html
   ├── styles.css
   └── scripts.js

3. افتح index.html في المتصفح
